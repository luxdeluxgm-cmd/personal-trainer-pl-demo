# flower-shop-pl-demo

A custom-coded, single-page website mockup for a fictional personal trainer. Built as a demonstration piece for my web development portfolio with a strict, editorial-style design.

## Tech Stack

* **HTML5**
* **Tailwind CSS**
* **Vanilla JavaScript**

## Local Development

No build tools required. Open any `.html` file in your browser to view the layout. To fully test the custom modal system and simulated contact form, serve the directory locally:

```bash
python3 -m http.server
```
Then navigate to http://localhost:8000.
